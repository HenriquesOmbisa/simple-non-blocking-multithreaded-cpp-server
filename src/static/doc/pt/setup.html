Como baixar, compilar e iniciar

Passo a passo local para iniciar o servidor em poucos minutos.

1. Clonar

git clone <url-do-repo>
cd simple-non-blocking-multithreaded-cpp-server

2. Build

cmake -S src -B build
cmake --build build

3. Executar

./build/mojoraw_example

4. Testar rapido

curl -i http://localhost:8080/hello
curl -i http://localhost:8080/json
curl -i http://localhost:8080/doc

Dependencias

Linux, CMake 3.16+, compilador C++20, gzip. ZLIB e opcional para gzip on-the-fly.
