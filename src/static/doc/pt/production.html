Guia de producao

Checklist para colocar o servidor em ambiente real.

Build e assets

O build gera .gz automaticamente para assets textuais em src/static, pronto para fallback eficiente.

Cache HTTP

  • ETag + If-None-Match (304)
  • Cache-Control normal e immutable para assets versionados
  • Vary: Accept-Encoding

Operacao recomendada

  • Rodar atras de Nginx/Caddy
  • TLS no proxy
  • Rate limiting
  • Logs e metricas

Bench basico

wrk -t4 -c100 -d10s http://localhost:8080/hello

Quick Commands

cmake -S src -B build
cmake --build build
./build/mojoraw_example
curl -i http://localhost:8080/hello
curl -i http://localhost:8080/doc/pt
