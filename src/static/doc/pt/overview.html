MojoRaw: o que e este projeto

Guia de introducao para quem acabou de baixar o repositorio.

Resumo

MojoRaw e um servidor HTTP/1.1 non-blocking em C++20 com epoll, multithread por SO_REUSEPORT, parser HTTP proprio, roteador com parametros e template engine.

Quem criou

O projeto nasceu em 2024 como iniciativa pessoal de aprendizado e evoluiu para uma base open source orientada a performance.

Para que serve

  • Aprender redes e servidores em C++.
  • Criar APIs e sites SSR leves.
  • Ter controle total sem framework pesado.

Quick Commands

cmake -S src -B build
cmake --build build
./build/mojoraw_example
curl -i http://localhost:8080/hello
curl -i http://localhost:8080/doc/pt
