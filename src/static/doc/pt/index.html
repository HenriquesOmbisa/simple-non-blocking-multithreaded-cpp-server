Guia real do MojoRaw

Este portal foi feito para guiar quem baixa o projeto: entender o que e, quem criou, como compilar, como criar rotas, como testar e como preparar para producao.

O que e / quem fez

Servidor HTTP/1.1 em C++20 criado inicialmente em 2024 por um entusiasta de C/C++, evoluido para uma base moderna open source.

Como iniciar

Compila com CMake e executa o binario. Em minutos ja tens hello/json/static/doc no ar.

Como evoluir

Adiciona rotas no Router, cria templates .mj.html e testa com curl/wrk.

Fluxo recomendado para novos contribuidores

  1. Ler Overview para entender o projeto.
  2. Executar Setup para compilar localmente.
  3. Abrir Routes para criar o primeiro endpoint.
  4. Usar Templates para SSR e paginas dinamicas.
  5. Conferir Production para cache, gzip e hardening.
