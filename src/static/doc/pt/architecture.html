Arquitetura do servidor

Como a engine de rede funciona internamente.

Modelo

Cada worker cria seu proprio socket de servidor e seu proprio epoll (SO_REUSEPORT), evitando lock global.

Ciclo de request

  1. accept4 non-blocking
  2. leitura em buffer
  3. validacao de request completa
  4. parse HTTP
  5. router dispatch
  6. serializacao da resposta
  7. write non-blocking

Protecoes

  • Limite de payload: 2MB (413)
  • Idle timeout: 30s
  • Path traversal bloqueado em static/doc

cmake --build build
./build/mojoraw_example
