Como criar novas rotas

Pratica para expandir API e paginas do projeto.

Onde editar

Arquivo principal: src/examples/basic_server.cpp.

Exemplo GET

router.get("/status", [](const HttpRequest&) {
  HttpResponse res;
  return res.json(R"({"ok":true})");
});

Exemplo com param

router.get("/users/:id", [](HttpRequest& req) {
  HttpResponse res;
  return res.json(std::string("{\"id\":\"") + req.param("id") + "\"}");
});

Teste

curl -i http://localhost:8080/status
curl -i http://localhost:8080/users/42
