Como usar templates .mj.html

Render server-side com sintaxe simples e poderosa.

Recursos

  • {{ var }} escaped
  • {{{ var }}} raw
  • {% if %}, {% elseif %}, {% else %}
  • {% for %}
  • {% include %}
  • {% extends %} + {% block %}

Exemplo

{% extends "layout.mj.html" %}
{% block content %}
  <h1>{{ name | upper }}</h1>
{% endblock %}

Render

Monte o contexto no C++ e chame TemplateEngine::renderFile(...).

Quick Commands

cmake -S src -B build
cmake --build build
./build/mojoraw_example
