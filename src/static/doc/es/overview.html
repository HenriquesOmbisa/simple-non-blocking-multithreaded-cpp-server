Que es MojoRaw

Introduccion del proyecto.

Servidor HTTP/1.1 en C++20 con epoll, multihilo y plantillas SSR.

Nacio en 2024 como proyecto de aprendizaje y evoluciono para uso real.

Quick Commands

cmake -S src -B build
cmake --build build
./build/mojoraw_example
curl -i http://localhost:8080/hello
curl -i http://localhost:8080/doc/es
